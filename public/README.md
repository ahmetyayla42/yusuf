# public klasörü

Buraya statik dosyalar konur.

## Logo ekleme

Kendi logonuzu göstermek için şeffaf arka planlı PNG dosyanızı bu klasöre
**`logo.png`** adıyla ekleyin.

En kolay yol (kod bilmeden, GitHub üzerinden):
1. GitHub'da repoyu açın → `public` klasörüne girin
2. **Add file → Upload files**
3. Logonuzu sürükleyin, adının **`logo.png`** olduğundan emin olun
4. **Commit changes**

Dosya eklendiğinde site otomatik olarak bu logoyu kullanır. `logo.png` yoksa
uygulama marka renkli bir yazı logosuna (yedek) düşer, hiçbir yer bozulmaz.
